guide d'intégration api

tout ce qu'il faut pour connecter votre frontend à l'api nathnotes. le backend tourne sur le port 3001.

authentification

nathnotes utilise des jwt tokens. le token est passé dans le header authorization: bearer <token> et stocké dans un cookie httpOnly.

post /api/auth/register

créer un nouveau compte utilisateur.

champtypedescription
emailstringemail unique
passwordstringmot de passe
namestringnom d'affichage
 
{
  "email": "nathanael@straumann.me",
  "password": "nathlecon1234",
  "name": "nathanael"
}

post /api/auth/login

connexion avec email et mot de passe.

{
  "email": "nathanael@straumann.me",
  "password": "nathlecon1234"
}

get /api/auth/me

infos de l'utilisateur connecté (protégé).

post /api/auth/logout

déconnexion (supprime le cookie).

gestion des notes

get /api/notes

récupérer toutes les notes non supprimées de l'utilisateur (protégé).

post /api/notes

créer une nouvelle note (protégé).

champtyperequisdescription
titlestringnontitre de la note
contentstringnoncontenu html de la note
folderstringnonid du dossier (défaut: "all")
 
{
  "title": "ma première note",
  "content": "
hello world
ceci est gras.
",
  "folder": "ideas"
}

put /api/notes/:id

modifier une note existante (protégé).

delete /api/notes/:id

suppression logicielle (déplace dans la corbeille, protégé).

get /api/notes/deleted

récupérer les notes supprimées (corbeille, protégé).

post /api/notes/:id/restore

restaurer une note depuis la corbeille (protégé).

soft delete — la note n'est pas définitivement supprimée, elle est déplacée dans la corbeille (deleted = 1).

gestion des dossiers

get /api/folders

récupérer tous les dossiers (dossiers par défaut + dossiers personnalisés, protégé).

dossiers par défaut — tout, travail, perso et idées sont toujours présents (is_default: true).

post /api/folders

créer un nouveau dossier personnalisé (protégé).

champtyperequisdescription
namestringouinom du dossier
iconstringnonemoji (défaut: "📁")
colorstringnoncouleur hex (défaut: "#e8b84b")
 
{
  "name": "mes projets",
  "icon": "🚀",
  "color": "#9b6ef3"
}
