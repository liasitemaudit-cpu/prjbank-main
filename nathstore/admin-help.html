guide d'import json

comment importer des produits en masse dans nathstore depuis le panel d'administration.

format attendu

l'import attend un tableau json (array) contenant un ou plusieurs objets produits. chaque objet représente un produit.

[{
  "nom": "air max 2026",
  "emoji": "👟",
  "categorie": "mode",
  "prix": 89.99,
  "description": "sneakers ultra confortables",
  "badge": "new"
}]

vous pouvez aussi importer un seul produit sans tableau — l'objet est converti automatiquement.

champs

champtyperequis ?descriptionexemple
nomstringouinom du produit affiché dans la boutique"air max 2026"
emojistringouiun seul emoji, affiché comme vignette produit"👟"
categoriestringouidoit être exactement l'une des valeurs valides, en minuscules"mode"
prixnumberouiprix en euros, décimal avec point (pas de virgule)89.99
descriptionstringnoncourte description affichée sous le nom"sneakers confortables"
badgestring | nullnonpetit label affiché sur la vignette. mettez null pour aucun badge."new" / "promo" / null
attention : si nom, emoji, categorie ou prix est manquant, le produit est ignoré et compté comme erreur. les autres produits du même fichier sont quand même importés.

catégories disponibles

le champ categorie doit être exactement l'une de ces 4 valeurs (en minuscules) :

emojinomvaleur
👟mode"mode"
💻tech"tech"
🎮gaming"gaming"
🍕food"food"
erreur fréquente : écrire "Mode" avec une majuscule ou "Mode 👟" avec l'emoji — l'api accepte uniquement les valeurs exactes en minuscules.

erreurs fréquentes

erreurcause
json invalidevirgule manquante, accolade non fermée, guillemets manquants. utilisez un validateur json en ligne avant d'importer.
produits ignoréschamps manquants (nom, emoji, categorie, prix). le message d'import affiche le nombre d'ignorés.
catégorie invalidela valeur n'est pas exactement "mode", "tech", "gaming" ou "food" en minuscules.
prix avec virguleen json, les décimaux s'écrivent avec un point : 29.99 et non 29,99.
serveur inaccessiblele backend node.js n'est pas lancé. tapez cd banque && node index.js dans un terminal.

conseils

  • validez votre json sur jsonlint.com avant d'importer.
  • importez par petits lots (20 à 30 produits) pour identifier plus facilement les erreurs.
  • créez un fichier produits.json dédié et utilisez l'onglet uploader.
  • le badge peut être n'importe quel texte court ("new", "promo", "top", "sold out", "limited"). gardez-le sous 10 caractères.
