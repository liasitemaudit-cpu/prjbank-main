sujet

NathBank, NathStore, NathNotes et NathChat forment un écosystème full-stack développé sans framework frontend. Quatre modules communiquent entre eux sur une seule machine en local. Ce projet a été conçu par Nathanaël dans le cadre d'un Bac Pro CIEL, option SNT.

L'audience est l'auteur, ses enseignants et les utilisateurs des outils. Le rôle de ce document est de décrire l'écosystème clairement, sans décor inutile.

lancement

depuis la racine du projet, sur Windows :

start-all.bat

le script lance le serveur Banque (port 3000), le serveur NathNotes (port 3001), puis ouvre NathBank, NathStore et NathNotes dans le navigateur.

lancement manuel :

cd banque && node index.js
cd nathnotes && node server.js
cd nathchat && node server.js
